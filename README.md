# Assignment-2-and-3
 Analysis of Existing Game:-

1. Game Overview

The original project is a simple command-line running/jumping game.
The player (P) attempts to avoid obstacles (#) by jumping at the right time.



2. Game Flow Summary
Game Start

Initializes player position and obstacle.

Starts main game loop.

Gameplay Loop

Obstacle moves left every frame.

Player can jump when user presses a key.

Collision detection checks if the player and obstacle meet.

Rendering

Screen is refreshed every frame.

Player and obstacle are printed in fixed positions.

Game End

Game ends once a collision is detected.

3. Strengths

Clean modular functions

Easy for beginners to understand

Simple, effective gameplay loop

4. Weaknesses

No score

No difficulty progression

Only one obstacle

No restart menu

Game is very short
